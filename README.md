# 최혁준 포트폴리오 쇼케이스

사람인 포트폴리오 첨부용 쇼케이스 앱입니다.

## 원본 보호 원칙

- `caredoc`, `Lucid`, `RealLife`, `subtitle-fix-checker` 원본 repo는 직접 수정하지 않습니다.
- 로그인 제거, 자동 진입, 데모 데이터 삽입은 이 쇼케이스 앱 또는 별도 복제본 안에서만 처리합니다.
- 원본 서비스의 운영 로그인/인증 흐름은 보존합니다.
- `source-clones/`는 원본 작업트리의 쇼케이스용 스냅샷입니다.
- `private`, `.vercel`, `.firebase`, `.claude`, `.omc`, `.hermes`, 테스트 리포트, `.git` 계열 폴더는 쇼케이스 복제본에서 제외합니다.

## 목표

- 자기소개서, 연락처, 작품별 데모 화면을 한 사이트 안에서 이동합니다.
- 태블릿 목업이 아니라 웹사이트 자체가 작품 전시장처럼 보이게 구성합니다.
- 로그인 없이 채용 담당자가 핵심 화면과 사용 흐름을 볼 수 있게 합니다.
